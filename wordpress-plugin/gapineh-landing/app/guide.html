رله‌ی گوگل برای تلگرام

سرورهای ایران معمولاً به api.telegram.org دسترسی ندارند؛ رله‌ی گوگل این پیام‌ها را از مسیر در دسترس عبور می‌دهد. وردپرس پیام را به اسکریپت گوگل می‌فرستد و اسکریپت آن را به تلگرام می‌رساند.

  1. در script.google.com یک پروژه‌ی جدید بسازید.
  2. کل محتوای فایل google-relay.gs همراه افزونه را جای کد پیش‌فرض بگذارید.
  3. مقدار SECRET را با یک رشته‌ی تصادفی بلند عوض کنید.
  4. از مسیر Deploy گزینه‌ی New deployment و نوع Web app را انتخاب کنید.
  5. Execute as را روی Me و Who has access را روی Anyone بگذارید و دسترسی‌ها را تأیید کنید.
  6. آدرس پایان‌یافته با /exec را در تنظیمات وردپرس و در بخش «اعلان‌ها، رله‌ی گوگل» وارد کنید.
  7. همان SECRET را در وردپرس هم وارد کنید.
  8. پس از هر تغییر در کد، در اسکریپت گوگل از مسیر Manage deployments ← Edit ← New version نسخه‌ی جدید بسازید.
/**
 * رلهٔ تلگرام گپینه — Google Apps Script
 *
 * چرا لازم است:
 *   سرورهای ایران به api.telegram.org دسترسی ندارند، ولی گوگل در دسترس است
 *   و سرور گوگل می‌تواند به تلگرام برسد. پلاگین پیام را به این اسکریپت
 *   می‌فرستد و این اسکریپت آن را به تلگرام می‌رساند.
 *
 * ─── راهنمای نصب ───
 * ۱) برو به https://script.google.com و یک پروژهٔ جدید بساز.
 * ۲) کل محتوای این فایل را جای کد پیش‌فرض بگذار و ذخیره کن.
 * ۳) Deploy ← New deployment ← نوع: Web app
 *      - Execute as:  Me
 *      - Who has access:  Anyone
 * ۴) دکمهٔ Authorize access را بزن و اجازه بده.
 * ۵) آدرسی که می‌دهد (…/exec) را در پیشخوان وردپرس بگذار:
 *      گپینه ← تنظیمات ← تب «اعلان‌ها» ← «رلهٔ گوگل»
 *
 * ⚠ اگر بعداً این کد را تغییر دادی، باید Deploy ← Manage deployments ←
 *   Edit ← Version: New version را بزنی وگرنه تغییرات اعمال نمی‌شوند.
 *
 * ─── امنیت ───
 * این Web App برای همه باز است (چون وردپرس نمی‌تواند لاگین گوگل داشته باشد).
 * برای اینکه غریبه‌ها نتوانند از آن سوءاستفاده کنند، یک «کلید مشترک» تعریف
 * شده: SECRET را پایین عوض کن و همان را در وردپرس هم وارد کن.
 */

// ── این را عوض کن (یک رشتهٔ تصادفی بلند) ──
var SECRET = 'گپینه-کلید-خودت-را-اینجا-بگذار';

function doPost(e) {
  var p = readParams(e);

  if (p.secret !== SECRET) {
    return json({ ok: false, error: 'unauthorized' });
  }

  if (!p.token || !p.chat_id || !p.text) {
    return json({ ok: false, error: 'missing token / chat_id / text' });
  }

  try {
    var url = 'https://api.telegram.org/bot' + encodeURIComponent(p.token) + '/sendMessage';

    var res = UrlFetchApp.fetch(url, {
      method: 'post',
      muteHttpExceptions: true,
      payload: {
        chat_id: p.chat_id,
        text: p.text,
        parse_mode: p.parse_mode || '',
        disable_web_page_preview: true
      }
    });

    var code = res.getResponseCode();
    var body = res.getContentText();

    if (code === 200) {
      return json({ ok: true });
    }

    // خطای تلگرام را برگردان تا در وردپرس قابل دیباگ باشد
    var parsed;
    try { parsed = JSON.parse(body); } catch (err) { parsed = null; }

    return json({
      ok: false,
      error: (parsed && parsed.description) ? parsed.description : ('telegram http ' + code + ': ' + body.slice(0, 200))
    });

  } catch (err) {
    return json({ ok: false, error: String(err) });
  }
}

/**
 * پشتیبانی از هر دو قالب: فرم (e.parameter) و JSON خام (e.postData.contents).
 */
function readParams(e) {
  var out = { token: '', chat_id: '', text: '', parse_mode: '', secret: '' };

  if (e && e.parameter && e.parameter.chat_id) {
    out.token = e.parameter.token || '';
    out.chat_id = e.parameter.chat_id || '';
    out.text = e.parameter.text || '';
    out.parse_mode = e.parameter.parse_mode || '';
    out.secret = e.parameter.secret || '';
    return out;
  }

  if (e && e.postData && e.postData.contents) {
    var raw = e.postData.contents;
    var data = null;
    try { data = JSON.parse(raw); } catch (err) { data = null; }

    if (data) {
      out.token = data.token || '';
      out.chat_id = data.chat_id || '';
      out.text = data.text || '';
      out.parse_mode = data.parse_mode || '';
      out.secret = data.secret || '';
      return out;
    }

    // فرم urlencoded خام
    var pairs = raw.split('&');
    for (var i = 0; i < pairs.length; i++) {
      var kv = pairs[i].split('=');
      if (kv.length < 2) continue;
      var k = decodeURIComponent(kv[0]);
      var v = decodeURIComponent(kv.slice(1).join('=').replace(/\+/g, ' '));
      if (k === 'token') out.token = v;
      if (k === 'chat_id') out.chat_id = v;
      if (k === 'text') out.text = v;
      if (k === 'parse_mode') out.parse_mode = v;
      if (k === 'secret') out.secret = v;
    }
  }

  return out;
}

/** برای تست دستی در مرورگر. */
function doGet(e) {
  return json({ ok: true, message: 'Gapineh Telegram relay is running.' });
}

function json(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}

دانلود فایل google-relay.gs

دو اشتباه رایج: اول، گذاشتن آدرسی که به /exec ختم نمی‌شود. دوم، تغییر کد بدون ساخت نسخه‌ی جدید؛ در این حالت تغییرات روی آدرس فعلی اعمال نمی‌شود.

کانال بله

  1. توکن ربات بله و شناسه‌ی گفتگو را وارد کنید.
  2. اعلان یک‌طرفه یا پاسخ دوطرفه‌ی اپراتور را انتخاب کنید.
  3. سایت باید روی HTTPS عمومی در دسترس باشد.
  4. ثبت webhook را اجرا و نتیجه را آزمون کنید.

اعلان‌ها←بله←ثبت webhook

پیامک و ایمیل

  1. ارائه‌دهنده‌ی پیامک را انتخاب کنید: کاوه‌نگار، ملی‌پیامک یا SMS.ir.
  2. کلید API، شماره‌ی فرستنده و شماره‌ی مدیر را وارد کنید.
  3. اعلان مدیر و بازدیدکننده را جداگانه فعال کنید.
  4. فاصله‌ی زمانی اعلان‌ها را برای جلوگیری از ارسال تکراری تعیین کنید.

گفتگوها، مخاطبین و آمار

سه بخشی که هر روز با آن‌ها کار می‌کنید، همه داخل پیشخوان وردپرس.

گفتگوها

مکالمات را جست‌وجو کنید، وضعیت خوانده‌نشده را ببینید، پاسخ دستی بدهید، مکالمه را واگذار کنید و از پیشنهاد پاسخ یا خلاصه‌ی مکالمه کمک بگیرید.

مخاطبین

نام، تلفن، ایمیل و سابقه‌ی مکالمه‌ی مشتریان را یک‌جا نگه دارید تا در گفتگوی بعدی لازم نباشد دوباره توضیح بدهند.

آمار

روند مکالمات، زمان پاسخ و وضعیت پاسخ‌گویی را برای تصمیم‌گیری بهتر بررسی کنید؛ مثلاً بفهمید بیشترین پرسش‌ها مربوط به کدام بخش محصول است.

بررسی سلامت

پیش از انتشار، همه‌ی آزمون‌های سلامت را اجرا کنید تا اتصال هوش مصنوعی، ایندکس، اعلان‌ها و webhook یک‌بار بررسی شود.

عیب‌یابی استاندارد

پنج مورد پرتکرار و کاری که واقعاً مشکل را حل می‌کند.

تست اتصال هوش مصنوعی خطا می‌دهد
کلید API، نام مدل، نشانی پایه و دسترسی هاست به اینترنت را بررسی کنید. ابتدا تنظیمات را ذخیره کنید و بعد آزمایش اتصال را اجرا کنید؛ تغییرهای ذخیره‌نشده در آزمون اعمال نمی‌شوند.
ویجت روی سایت دیده نمی‌شود
فعال‌بودن ویجت و چت آنلاین را بررسی کنید، کش سایت و CDN را پاک کنید و با پنجره‌ی خصوصی مرورگر تست بگیرید. اگر ویجت فقط در بعضی برگه‌ها نمایش داده می‌شود، تنظیم نمایش را بازبینی کنید.
تلگرام پیام نمی‌فرستد
توکن، شناسه‌ی گفتگو، عضویت ربات در گروه و یکسان‌بودن کلید مشترک را بررسی کنید. اگر سرور به تلگرام دسترسی ندارد، رله‌ی گوگل را فعال کنید و آدرسی که با /exec تمام می‌شود را وارد کنید.
تغییرهای رله اعمال نمی‌شود
در اسکریپت گوگل باید از مسیر Manage deployments وارد Edit شوید و Version: New version را انتخاب کنید. بدون این کار، آدرس فعلی همان کد قدیمی را اجرا می‌کند.
تنظیمات ذخیره نمی‌شود
با کاربر مدیرکل وارد شوید، کش را پاک کنید و مطمئن شوید افزونه دوباره حذف و نصب نشده است. پیش از تغییرات مهم، از دکمه‌ی خروجی تنظیمات پشتیبان بگیرید تا بازگردانی ساده باشد.

  • یک مکالمه‌ی آزمایشی روی موبایل و دسکتاپ انجام شده باشد.
  • اعلان کانال‌های فعال (تلگرام، بله، پیامک یا ایمیل) تست شده باشد.
  • ساعت کاری و واگذاری مکالمه آزمایش شده باشد.
  • خروجی تنظیمات (JSON) برای پشتیبان‌گیری ذخیره شده باشد.
