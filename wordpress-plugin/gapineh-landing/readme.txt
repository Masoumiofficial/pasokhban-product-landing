لندینگ و راهنمای گپینه روی /gapineh/ + شورت‌کد [gapineh_landing] برای المنتور.

== توضیحات ==
این افزونه نسخهٔ تأییدشدهٔ لندینگ گپینه (سه‌بعدی، شبیه‌ساز، دمو) را بدون تغییر
روی سایت وردپرسی منتشر می‌کند:

* لندینگ: yoursite.com/gapineh/
* راهنما: yoursite.com/gapineh/guide/
* شورت‌کد [gapineh_landing] برای نمایش لندینگ داخل برگه‌های المنتور (ابزارک کد کوتاه)
* دو قالب برگهٔ تمام‌صفحه برای نمایش مستقیم بدون آی‌فریم

راهنمای نصب کامل داخل فایل INSTALL.txt افزونه است.

== نصب ==
۱. از پیشخوان: افزونه‌ها ← افزودن ← بارگذاری افزونه ← انتخاب زیپ ← فعال‌سازی
۲. پیوندهای یکتا را روی «نام نوشته» بگذارید (تنظیمات ← پیوندهای یکتا)
۳. برگهٔ المنتوری بسازید، ابزارک «کد کوتاه» با [gapineh_landing] بگذارید، منتشر کنید.
